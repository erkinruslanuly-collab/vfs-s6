# S6 · Жадтағы файлдық жүйе (VFS)

## Құрастыру және тестілеу

Java 17 және Maven қажет:

```powershell
mvn clean verify
```

## Қамтылған функционал

- Composite файл ағашы және inode негізіндегі hard link қолдауы
- Файл ашу, оқу/жазу, іздеу, атауын өзгерту, жою және символдық сілтемелер
- Visitor (`du`, `find`, `chmodRecursive`), iterator және proxy үлгілері
- Оқу/жазу операцияларын үйлестіретін lock
- java.nio-пен дифференциалды тесттер және ArchUnit архитектуралық ережесі

Тесттердің өтуі `mvn clean verify` іске қосылғаннан кейін ғана расталады.
