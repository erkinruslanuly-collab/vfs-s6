# java.nio мен VFS мінез-құлқының айырмашылықтары

1. Каталогтың `stat().size()` мәні VFS ішінде ішкі элементтер санын көрсетеді.
2. Символдық сілтемелер әдепкіде `0777` құқығымен жасалады; сілтеме циклінің шегі — 40 деңгей.
3. VFS ашық файлды жоюға және қайта атауға POSIX тәрізді рұқсат береді, ал операциялық жүйенің файлдық жүйесі өзгеше әрекет етуі мүмкін.
4. Қателер операциялық жүйеге тәуелді `IOException` орнына `VfsException` және POSIX кодымен беріледі.
