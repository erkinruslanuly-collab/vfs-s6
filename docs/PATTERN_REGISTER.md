# Дизайн үлгілерінің тізілімі

## Қолданылған үлгілер

1. **Composite** — `VfsNode`, `VfsFile`, `VfsDirectory`, `VfsSymLink` файлдар ағашын ортақ интерфейспен ұсынады.
2. **Facade** — `VirtualFileSystem` API ішкі файл ағашының құрылымын жасырады.
3. **Iterator** — `LazyDirectoryIterator` каталогтарды тереңдік бойынша аралайды.
4. **Visitor** — `du`, `find` және `chmodRecursive` операцияларын түйін кластарынан бөлек ұстайды.
5. **Proxy** — `SecurityProxyNode` құқықтарды тексереді, `LazyContentFileProxy` мазмұнды алғашқы оқу кезінде жүктейді.

## Қабылданбаған үлгілер

- **Singleton:** бірнеше тәуелсіз VFS данасын қолдауға кедергі келтірер еді.
- **Observer:** бұл жобаның API талаптарында оқиға тарату қарастырылмаған.
