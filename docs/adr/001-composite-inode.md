# ADR-001: Composite және Inode архитектурасы

- **Статус:** Қабылданды
- **Контекст:** Файлдар ағашын және hard link ортақ деректерін ұсыну қажет.
- **Шешім:** Түйіндер `VfsNode` иерархиясымен беріледі, файл деректері `Inode` ішінде сақталады.
- **Салдары:** Бірнеше файл түйіні бір inode-ты бөлісе алады; жою link count-ты азайтады.
