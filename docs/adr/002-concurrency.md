# ADR-002: Көп ағындылық және атомарлы өзгерістер

- **Статус:** Қабылданды
- **Контекст:** VFS операциялары қатар орындалғанда құрылым тұтастығын сақтау қажет.
- **Шешім:** Оқу және жазу операцияларын `ReentrantReadWriteLock` арқылы үйлестіру.
- **Салдары:** Құрылымдық жазулар атомарлы орындалады; файл дескрипторындағы позиция бөлек синхрондалады.
