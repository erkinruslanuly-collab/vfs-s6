# ADR-003: POSIX мінез-құлқы және операциялық жүйе айырмашылықтары

- **Статус:** Қабылданды
- **Контекст:** Файл жүйесінің кейбір операциялары Windows пен Unix жүйелерінде әртүрлі болуы мүмкін.
- **Шешім:** VFS үшін детерминді виртуалды семантиканы таңдап, айырмашылықтарды `docs/differences.md` ішінде тіркеу.
- **Салдары:** Тестілеу қоршаған операциялық жүйенің ұсақ ерекшеліктеріне азырақ тәуелді болады.
